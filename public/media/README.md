# 首屏视频素材放这里

首屏 Hero 的背景视频支持自动启用：把文件按下面的名字放进本目录即可，无需改代码。

- `hero-loop.mp4`（优先）
- `hero-loop.webm`（可选，兼容用）
- `hero-poster.jpg`（可选，视频加载前 / 未启用视频时的静态封面）

## 建议规格

| 项目 | 建议值 |
| --- | --- |
| 分辨率 | 2560×1440（或 1920×1080） |
| 时长 | 8–15 秒无缝循环 |
| 码率 | 4–8 Mbps |
| 音轨 | 无（muted + autoplay 才能自动播放） |

如果目录里没有视频文件，页面会自动使用内置的动态光影背景，效果同样完整，
不会出现黑屏或报错。
